# Gallery

Gallery shows a set of images from selected folder on SD Card.
Image format (1bit or 3bit) is automatically detected and displayed.
Gallery reacts to left/right swipe gestures to navigate between images.

Tap on the lower area of the screen toggles mode "playback" vs "still image".
It shows activated mode in the lower center area, "resumed" or "paused".
Mode shows with partial update and hides with full update after 3 seconds.

Tap on teh upper area of the screen opens settings overlay.
Settings overlay contains a "folder" icon, delay control and "back" button.

Folder icon opens folder selection overlay, which shows all folders on SD Card.
Delay control allows to set delay between images in "playback" mode.
