# Meditamer

Meditamer is an offline-first e-ink companion designed to bring time back to a
human scale. This repository contains its Rust firmware, platform libraries,
hardware targets, host tooling, and supporting documentation.

The primary device target is the ESP32-based Inkplate 4 TEMPERA, built with `esp-hal` and Embassy.
